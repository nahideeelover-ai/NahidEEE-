কেন এই সেটআপ প্রয়োজন?
GitHub Pages একটি স্ট্যাটিক হোস্টিং। সব ডিভাইসে একই পণ্য ও অর্ডার দেখানোর জন্য Supabase ক্লাউড ডাটাবেস সংযোগ প্রয়োজন। Supabase URL ও Publishable/anon key এখানে বসাতে হবে। Secret বা service_role key কখনো এখানে দেবেন না।

Supabase Project URL ও Publishable/anon key অ্যাডমিন লগইন বক্সে প্রথমবার সেটআপ করা হয়। পরিবর্তন করতে লগইন বক্সে গিয়ে সংযোগ তথ্য আপডেট করুন। service_role/secret key কখনো ব্যবহার করবেন না।

নিরাপত্তার জন্য এই ব্রাউজার-ভিত্তিক সংস্করণে Telegram Bot Token ব্যবহার বন্ধ রাখা হয়েছে। পরে নিরাপদ server-side function দিয়ে যুক্ত করতে হবে।

Supabase-এর পাবলিক ক্লায়েন্ট কনফিগারেশন ওয়েবসাইটে স্বয়ংক্রিয়ভাবে ব্যবহৃত হয়। কোনো Secret বা service_role key এই HTML ফাইলে রাখা যাবে না। Telegram Bot Token নিরাপদ সার্ভার-সাইড ব্যবস্থা ছাড়া এখানে ব্যবহার করা হয় না।
